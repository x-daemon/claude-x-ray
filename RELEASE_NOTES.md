# S2A Claude X-Ray 0.2.0

Нативное приложение для macOS 14+ (Apple Silicon и Intel): использование Claude Code в реальном времени и по истории, API‑эквивалент для подписки Pro/Max, Live‑трасса и подсказки по оптимизации.

## Что нового

- **Тема S2A** по умолчанию: фирменный фиолетовый, циан и глубокий ночной фон, иконка приложения, шапка в боковой панели. Цвета графиков проверены на различимость при протанопии и дейтеранопии в светлом и тёмном режиме. Переключение в «Настройки → Оформление» (S2A или системная; режим: как в системе, светлый, тёмный).
- **Live‑трасса**: что Claude делает прямо сейчас — лента, поток ходов, таймлайн, контекст, инструменты, MCP, скиллы и субагенты.
- Обзор, сессии, проекты, модели, оптимизация, отчёты Markdown/CSV, статус в строке меню.

## Установка

1. Откройте `S2A-Claude-X-Ray-0.2.0.dmg` и перетащите **S2A Claude X-Ray** в «Программы» (или распакуйте `.zip`).
2. Сборка подписана ad‑hoc, без Apple Developer ID, поэтому при первом запуске macOS покажет предупреждение. Нажмите «Готово», затем откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» напротив S2A Claude X-Ray.

   Или одной командой в Терминале:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/S2A Claude X-Ray.app"
   ```

3. Приложение читает `~/.claude/projects` (или `$CLAUDE_CONFIG_DIR/projects`) и никуда не отправляет данные.

Проверить целостность: `shasum -a 256 -c SHA256SUMS.txt`.
